# Моя оболонка для Tanix TX68 (Android 12)

Проста оболонка (лаунчер) у стилі вашого скріншота: привітання, великий годинник, дата,
назва вибраної програми та один чистий ряд плиток у напівпрозорій панелі.

- Керується пультом: ліво/право, OK. **Довге натискання OK** на плитці відкриває налаштування
  програми (видалити, очистити кеш).
- Плитка «Усі програми» показує повний список; «Назад» повертає на головний ряд.
- Кнопка Home на пульті повертає на головний ряд.
- Стару оболонку **не видаляємо**: вона залишається в системі, і до неї можна повернутися.

---

## 1. Як отримати APK

Тут немає готового APK, бо його потрібно зібрати. Є два шляхи.

### Варіант А. Без встановлення програм: збірка на GitHub (рекомендую)

1. Зареєструйтесь на https://github.com (безкоштовно).
2. Натисніть **New repository**, назвіть, наприклад, `myhome`, залиште **Public** або **Private**, створіть.
3. На сторінці репозиторію натисніть **uploading an existing file** і перетягніть **усі файли та папки
   з розпакованого архіву** (разом із прихованою папкою `.github`). Якщо веб-інтерфейс не бере
   `.github`, створіть файл вручну: **Add file → Create new file**, у назві введіть
   `.github/workflows/build.yml` і вставте вміст файлу з архіву.
4. Перейдіть у вкладку **Actions**. Якщо збірка не стартувала сама, виберіть **Build APK → Run workflow**.
5. Через 3–6 хвилин відкрийте завершений запуск, внизу в розділі **Artifacts** завантажіть `MyHome-apk`.
   Це zip, у ньому файл `app-release.apk`. Перейменуйте його на `myhome.apk`.

### Варіант Б. Android Studio на комп'ютері

1. Встановіть Android Studio, відкрийте папку проєкту (**Open**).
2. Дочекайтеся синхронізації Gradle.
3. **Build → Build Bundle(s) / APK(s) → Build APK(s)**. APK буде в `app/build/outputs/apk/release/`.

## 2. Як встановити на приставку

### Спосіб 1. Через ADB по Wi‑Fi (зручніше, потрібен комп'ютер)

1. На приставці: **Налаштування → Про пристрій** (або «Про систему»), 7 разів натисніть на **Номер збірки**.
   З'явиться режим розробника.
2. **Налаштування → Для розробників**: увімкніть **Налагодження USB** (на частині приставок також є
   **Налагодження по мережі / ADB по Wi‑Fi**).
3. Дізнайтесь IP приставки: **Налаштування → Мережа** (наприклад, `192.168.1.50`).
4. Встановіть ADB на комп'ютер (пакет «Android platform-tools» від Google), відкрийте термінал у його папці.
5. Виконайте:

```
adb connect 192.168.1.50:5555
adb install -r myhome.apk
```

На екрані телевізора підтвердьте запит **Дозволити налагодження**. Має з'явитися `Success`.

### Спосіб 2. Через флешку (без комп'ютера з ADB)

1. Скопіюйте `myhome.apk` на флешку, вставте її в приставку.
2. Відкрийте на приставці будь-який файловий менеджер (Files, X-plore тощо), знайдіть APK і натисніть OK.
3. Якщо система попросить, дозвольте **встановлення з невідомих джерел** для цього файлового менеджера.
4. Натисніть **Встановити**.

---

## 3. Як зробити її оболонкою за замовчуванням

**Спосіб 1 (найпростіший).** Натисніть кнопку **Home** на пульті. Система запитає, яку оболонку використати:
виберіть **Моя оболонка** і **Завжди**.

**Спосіб 2.** **Налаштування → Програми → Програми за замовчуванням → Домашній екран** (назва залежить від
прошивки), виберіть **Моя оболонка**.

**Спосіб 3 (через ADB, якщо прошивка ховає вибір).**

```
adb shell cmd package set-home-activity com.tanix.myhome/.MainActivity
```

> Деякі прошивки Tanix мають власний «захист» оболонки або не показують вікно вибору. Тоді працює саме
> Спосіб 3. Якщо і він не допоможе, напишіть мені, що саме показує приставка, і я підкажу інший шлях.

---

## 4. Як повернути стару оболонку

1. Перед змінами запишіть назву старої оболонки: `adb shell cmd shortcut get-default-launcher`
   (виведе щось на кшталт `ComponentInfo{com.xxx/com.xxx.Main}`).
2. Щоб повернутися:

```
adb shell cmd package set-home-activity com.xxx/com.xxx.Main
```

3. Або видаліть нову оболонку, і система сама поверне стару:

```
adb uninstall com.tanix.myhome
```

Також можна: **Налаштування → Програми → Моя оболонка → Очистити за замовчуванням / Видалити**.

## 5. Як налаштувати під себе

| Що змінити | Де |
|---|---|
| Які програми закріплені першими і в якому порядку | `app/src/main/res/values/config.xml` → `pinned_packages` |
| Які програми приховати | там само → `hidden_packages` |
| Кольори фону | `res/drawable/bg_home.xml` |
| Прозорість і форма панелі | `res/drawable/panel_bg.xml` |
| Розмір плиток | `res/layout/item_app.xml` (`176dp × 99dp`) |
| Тексти привітань | `res/values/strings.xml` |

Назви пакетів у `config.xml` наведені за звичним шаблоном; частину з них (MEGOGO, Sweet.TV, HBO Max) варто
перевірити на вашій приставці командою `adb shell pm list packages | grep -i megogo` і за потреби поправити.
Після змін потрібно заново зібрати APK (розділ 1) і встановити поверх (`adb install -r`).

## Чесно про обмеження

- Проєкт підготовлено без запуску на вашій приставці: я не міг перевірити його на реальному пристрої.
  Якщо збірка або запуск дадуть помилку, надішліть текст помилки, і я виправлю.
- Плитки використовують «банери» програм, які надають самі програми для Android TV. Якщо банера немає,
  показується іконка з назвою.
- Дизайн повторює лише компонування зі скріншота. Логотипів і брендингу сторонніх сервісів у проєкті немає.
